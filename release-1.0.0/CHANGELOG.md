# Changelog

## 1.0.0 – 2026-10-12
- Erste lokale MCP-Bridge-Version für Blender 4.2+ (Ziel: Blender 5.2.2 LTS).
- Scene inspection, primitive/camera/light creation, transforms, duplicates, materials, keyframes, validation and selected non-destructive repair tools.
- Approval UI for deletion, rendering, saving a project copy and running Python.
- Project-folder restrictions and append-only JSONL audit log.
- Dependency-free stdio MCP server and optional token-protected Streamable HTTP server.
- Python execution disabled by default.
